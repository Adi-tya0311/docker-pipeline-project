## 🎯 Why This Project Exists

Most beginner projects stop at "it runs on my machine." **Feasto doesn't.**

The frontend — a Swiggy/Zomato-style food-ordering interface — is intentionally simple. That's the point: **the application is a vehicle, not the destination.** What actually matters here is everything happening *around* it — a real CI/CD pipeline that takes a one-line code change and turns it into a live deployment with zero manual steps.

If you're evaluating this repo for what it teaches, look past the HTML and look at the `Jenkinsfile`.


```
  CODE  →  VERSION CONTROL  →  CI/CD  →  CONTAINER  →  CLOUD  →  🌍 LIVE
```
